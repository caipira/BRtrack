# BRtrack — Landing Page

Landing page responsiva construída com **Bootstrap 5**.

## Como executar

Abra o `index.html` no navegador ou sirva a pasta:

```bash
npx serve .
# ou
python -m http.server 8000
```

## Estrutura

- `index.html` — página única (hero, recursos, números, planos, contato e rodapé)
